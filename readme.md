## Featured Projects

### 💰 [Gonami](https://github.com/derispewss/gonami-projects)

A personal finance assistant on WhatsApp. Users log income, expenses, and transfers in natural Indonesian through text, voice notes, receipt photos, or PDFs, and Gemini AI extracts the transaction details. It uses a two-layer parser (deterministic first, LLM fallback second) to keep token usage low, and ships with budgets, multi-wallet support, and report export.

### 🧠 [IndoBERT Slang Normalization (LOSO)](https://github.com/derispewss/indobert-slang-normalization-loso)

Research on how Indonesian slang normalization affects IndoBERT's cross-platform generalization for e-commerce sentiment analysis. It uses a Leave-One-Site-Out evaluation between Tokopedia and Shopee reviews, comparing baseline and normalized models. Includes the full pipeline, a FastAPI REST API, and a Streamlit demo dashboard.
